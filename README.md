# Помощник первокурсника ИВТ МИЭМ

Прототип отвечает на вопросы по программам дисциплин первого курса НИУ ВШЭ за 2026/2027 учебный год. Он показывает темы, формулы оценивания по модулям, контроль, литературу и тематические пересечения между дисциплинами. Вместе с ответом он выдаёт ссылки на соответствующие разделы карточек ВШЭ.

[Отчёт о прогоне 30 вопросов](RESULTS.md) · [Презентация решения (PDF)](presentation.pdf)

## Запуск

Нужен Python 3.10 или новее. Скачайте репозиторий и откройте терминал в его корневой папке.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python assistant.py
```

На Windows в PowerShell команды создания и активации окружения выглядят так: `py -m venv .venv` и `.\.venv\Scripts\Activate.ps1`. Если запуск скриптов PowerShell ограничен, можно обращаться к `.\.venv\Scripts\python.exe` напрямую.

Введите вопрос и нажмите Enter. Для выхода из интерактивного режима используйте Ctrl+C. После установки зависимости помощник работает локально. Интернет нужен, чтобы открыть ссылки.

Примеры запуска с одним вопросом:

```bash
python assistant.py "Где изучают FPGA?"
python assistant.py "Какая формула оценки по дискретной математике в 4-м модуле?"
python assistant.py "Что общего у обычной информатики и углублённой информатики?"
```

## Как выбирается ответ

1. Слова приводятся к нижнему регистру и основам с помощью русского стеммера Snowball. По названию и сокращениям определяется дисциплина и её вариант. Если название не указано, для поиска тем используется BM25.
2. По формулировке запроса выбирается раздел программы: темы, аттестация, литература, контроль или общие сведения. Для двух названных дисциплин можно запросить сопоставление тем.
3. Ответ собирается из выбранных полей. В нём могут быть несколько ссылок или просьба уточнить название. Для формул сохраняются коэффициенты и названия компонентов из источника, включая повторы компонентов.

Такой подход позволяет воспроизводить ответы и сверять их с первоисточниками. Формулы берутся из подходящего модуля и учебного года. Внешняя LLM и сетевые запросы при ответе не используются.

## Корпус и ограничения

В `courses.json` включены 26 карточек с [первой страницы каталога ВШЭ](https://www.hse.ru/ba/isct/courses?course=1.1.1.4&page=1&year=2026) и [второй страницы](https://www.hse.ru/ba/isct/courses/page2.html?course=1.1.1.4&year=2026). Проверены пометки «1-й курс» и «2026/2027». Снимок подготовлен 22 ноября 2026 года. Темы собраны в короткие сводки, библиографические записи, формулы и названия контроля привязаны к исходным карточкам. Две из 26 карточек содержат общие сведения и аннотации, но в них отсутствуют подробные разделы тем, оценивания и литературы.

Прототип может пропустить редкий синоним или частную тему внутри раздела, а по общему термину — показать несколько близких дисциплин. При сравнении он сопоставляет названия тем и не подтверждает официальные пререквизиты. Данные из LMS, расписание и индивидуальные оценки в корпус не входят. За один запрос выбирается один тип ответа. Библиография в CLI сокращена до трёх записей на раздел, полные списки доступны в источниках.

## Воспроизведение тестов

```bash
python evaluate.py > RESULTS.md
```

Скрипт проверяет 20 рабочих вопросов по ключевым фактам и адресам источников и воспроизводит 10 случаев ограничений. В отчёте записан фактический ответ на каждый вопрос. Набор демонстрационный.
